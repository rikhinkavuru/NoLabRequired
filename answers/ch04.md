# Chapter 4. Your one and only setup

## Exercise 4.1

**Goal.** Run `notebooks/setup.ipynb` from top to bottom and record the line it
prints at the end.

**Answer.** One line, from the last code cell, in this shape:

```
NLR setup OK | Python <version> | Linux | <today's date>
```

Three fields, and only one of them is fixed in advance. The version is whatever
Python the Colab machine is running the evening you open it, and it goes up over
time. The date is today's, written as year, month, day. The middle field reads
`Linux`, and it reads `Linux` whatever kind of computer you're sitting at.

The cells above it print their own output, and none of that is the answer:

- Cell 1 prints `4`.
- Cell 2 prints a Python version, then `running on Linux` with a machine name
  after it.
- Cell 3 prints how many databases NCBI lists, then five lines reading `gene`,
  `nuccore`, `protein`, `clinvar` and `gds`, each followed by `present`.
- Cell 4 prints a version beside `numpy`, `pandas`, `matplotlib` and `scipy`,
  then a line saying biopython isn't installed yet. That line is correct.
  Chapter 17 installs it.

**Why.** The last cell builds its string out of three calls:
`platform.python_version()`, `platform.system()` and
`datetime.date.today().isoformat()`. `platform.system()` reports the operating
system of the machine the code ran on, and your code didn't run on your laptop.
It ran on a Linux machine at Google that Colab started for you. That's the
chapter's opening question answered by the machine itself rather than by the
book.

**The most common wrong answer.** Writing `Windows`, or `Darwin`, or whatever
your own laptop runs. It comes from reading "record the line it prints" as
"describe your setup". Nothing you own appears anywhere in that line.

The second most common is copying cell 2's two lines instead of cell 5's one
line, because cell 2 also prints a Python version and a system name and looks
like the answer. The line you want starts `NLR setup OK`.

A third one worth naming: seeing `biopython  not installed yet` in cell 4 and
stopping, on the reading that setup failed. It hasn't. That message is the
expected state of a fresh Colab machine, and the exercise's check tells you
to write down any `MISSING` or `NOT INSTALLED` line and carry on.
