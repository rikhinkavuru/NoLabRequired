# Chapter 9. Checkpoint: what you just did

## Exercise 9.1

**Goal.** Write the methods paragraph for the search that named the fish in
Exercise 6.1.

**Answer.** Four sentences carrying five things. Here's the paragraph:

```
The 649-base query in mystery_fillet_1.fasta was searched against the
NCBI Core nucleotide BLAST database (128,547,243 sequences;
948,086,538,397 letters) with blastn (BLASTN 2.17.0+) on 2 August 2026.
The hit list was capped at 50. The best-scoring hit was Gadus
chalcogrammus AB182303.1 at 1,199 bits, with 649 of 649 identities and
no gaps. Forty-nine of the 50 hits carried a Gadus chalcogrammus name.
```

Point at the five as a reader would:

| The thing | Where it is |
|---|---|
| Query as a filename and a base count | `mystery_fillet_1.fasta`, 649 bases |
| Database name | NCBI Core nucleotide BLAST database |
| Program name | blastn, BLASTN 2.17.0+ |
| Date | 2 August 2026 |
| Top hit with version suffix and bit score | `AB182303.1`, 1,199 bits |

Every one of those came off the header block above the hit table, which is the
part of a BLAST report nobody reads.

**Why there's no E-value in it.** The report printed `0.0` for this hit, which
means the number came out smaller than the report can print rather than that it
came out at zero. A `0.0` can't be compared against another `0.0`, and on its own
it doesn't say which database produced it. The bit score has no floor to hit, so
it's the number that survives being written down.

**Why the last sentence is there.** The fourth sentence isn't decoration. It's
the evidence, and without it the paragraph is a claim about one row. A stranger
reading the first three sentences can repeat your search. A stranger reading all
four knows why the answer isn't a coin flip between tied rows.

**Notice what the paragraph doesn't claim.** It doesn't say the packet was
mislabeled, it doesn't say who swapped anything, and it doesn't call the fish
pollock in English. It names a query, a pile, a day, a hit and a score. Every
other claim you want to make is yours to argue for separately, in a different
paragraph.

**The most common wrong answer.** Naming the website instead of the database.
"Searched on NCBI BLAST" reads like it says where the search went, and it
doesn't. NCBI serves several nucleotide databases through the same form, and the
one you pick changes both the hit list and the E-values. A paragraph that names a
website fails the exercise's real test: could a stranger get a hit table for the
same query against the same pile?

The second most common is dropping the version suffix off the accession, which
Chapter 9's If-it-breaks section names as one of the two things that go missing
most. Chapter 5 is where the reason lives.

The third is writing a paragraph that describes the conclusion rather than the
method. "I used BLAST to identify the fish as Alaska pollock" is one sentence,
it's true, and nobody can repeat anything from it.
